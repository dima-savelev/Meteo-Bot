# Meteo62 NMU Monitor Bot

Асинхронный сервис на C# (.NET) для периодического мониторинга предупреждений о неблагоприятных метеорологических условиях (НМУ) с сайта [meteo62.ru/opnmu](https://meteo62.ru/opnmu) и отправки уведомлений в Telegram.

Ключевая особенность архитектуры — **строгая изоляция исходящего трафика парсера через Cloudflare WARP** на сетевом уровне с сохранением прямой доставки сообщений в Telegram через IP хоста.

---

## Архитектура и особенности

* **Изоляция парсинга через WARP (`docker-warp-native`):** Контейнер бота делит сетевой неймспейс (`network_mode: "service:warp-bot"`) с контейнером Cloudflare WARP. Исходящие запросы жестко привязываются к IP-адресу интерфейса WireGuard (`172.16.0.2`) через кастомный `SocketsHttpHandler.ConnectCallback`. Реальный IP сервера никогда не светится на целевом ресурсе.
* **Раздельные сетевые маршруты:** `TelegramBotClient` отправляет сообщения напрямую через физический интерфейс сервера, благодаря чему уведомления о сбоях доставляются даже при деградации VPN-туннеля.
* **Защита от утечки сокетов:** Настроены `PooledConnectionLifetime` (15 мин) и `PooledConnectionIdleTimeout` (2 мин) для корректной ротации TCP-соединений в Linux и предотвращения зависания сокетов в `TIME_WAIT` / `CLOSE_WAIT`.
* **Анти-флэппинг система оповещений:** Многоступенчатая верификация сбоев (повторная проверка через 20 секунд, затем пауза 5 минут перед алертом, а также 30-минутный кулдаун после восстановления) исключает ложный спам статусами «упал / восстановился».
